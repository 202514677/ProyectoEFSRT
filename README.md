# Sistema ERP Clínico en PHP
# Descripción General
El presente proyecto consiste en el desarrollo de un sistema ERP clínico web orientado a la administración y gestión de procesos internos de una clínica local. El sistema ha sido desarrollado utilizando tecnologías web como PHP, MySQL, HTML, CSS, JavaScript y Bootstrap, bajo una arquitectura modular organizada por componentes.
El objetivo principal del proyecto es digitalizar y optimizar tareas administrativas relacionadas con la gestión de pacientes, médicos, consultorios, citas y usuarios, permitiendo mejorar el control de la información y la eficiencia operativa dentro de la clínica.
El proyecto será desarrollado progresivamente en tres entregables académicos, incorporando nuevas funcionalidades, mejoras visuales, validaciones, reportes y mecanismos de seguridad hasta alcanzar una versión final funcional desplegada en un entorno web público.
